## 🚀 Featured Projects

### [Student-Mentor Portal](https://github.com/Manikandan-senthil/query-raising-react)
`MongoDB` · `Express.js` · `React` · `Node.js` · `WebSockets`

A role-based portal where students and mentors get separate dashboards.
Students view daily class schedules and course details, and raise tickets
for doubts related to class topics. The relevant mentor picks up matching
tickets, opening a real-time chat (built with WebSockets) to discuss and
resolve the issue.

**Key features:**
- Role-based authentication and access control (JWT, bcrypt)
- Multi-page student and mentor dashboards
- Ticket-raising and routing system
- Real-time student–mentor chat via WebSockets

🔗 Frontend: [query-raising-react](https://github.com/Manikandan-senthil/query-raising-react)
🔗 Backend: [query-raising-node](https://github.com/Manikandan-senthil/query-raising-node)
